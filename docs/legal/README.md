# Legal and privacy register

What Eye Drop Tracker publishes and keeps, the law each document answers to, and what is still open. Drafts dated 6 November 2026. All need review by a Canadian lawyer with health privacy experience before they are relied on.

## Documents

| Document | Where | Audience | Answers to |
| --- | --- | --- | --- |
| Terms of use | public/terms.html | Everyone | Ontario contract and consumer law, Health Canada SaMD guidance |
| Clinic terms | public/clinic-terms.html | Clinics and clinicians | PHIPA s. 10(4), O. Reg. 329/04 s. 6, provincial equivalents. Serves as the written agreement with each custodian |
| Privacy notice | public/privacy.html | Everyone | PHIPA, PIPEDA and its ten principles, Quebec Law 25, other provinces |
| Security page | public/security.html | Clinics, reviewers | Public description of services and safeguards (O. Reg. 329/04 s. 6(3)) |
| security.txt | public/.well-known/security.txt | Security researchers | RFC 9116 |
| Accessibility statement | public/accessibility.html | Everyone | Accessibility for Ontarians with Disabilities Act, WCAG 2.1 AA |
| Privacy impact assessment and threat risk assessment | docs/legal/privacy-impact-assessment.md | Clinic privacy officers | IPC Ontario PIA guide, O. Reg. 329/04 s. 6(3) |
| Incident and breach response plan | docs/legal/incident-response-plan.md | Makers | PHIPA s. 12, PIPEDA s. 10.1 and SOR/2018-64, Law 25 |
| Clinical safety case | docs/legal/clinical-safety-case.md | Makers, clinics | Health Canada SaMD guidance |
| Confidentiality undertaking | docs/legal/confidentiality-undertaking.md | Makers, contributors | O. Reg. 329/04 s. 6(1) |
| Chrome Web Store listing | docs/CHROME_STORE.md | Google review | Chrome Web Store user data policy |

## Compared with Ocean

| Item | Ocean | Eye Drop Tracker |
| --- | --- | --- |
| PHIPA role stated | Only in Ontario Health's PIA | Stated in the privacy notice and clinic terms |
| Laws named in the privacy policy | None by name | PHIPA, PIPEDA, Law 25, provincial acts |
| Data residency | Canada, with service providers possibly outside | No patient data held. Host and email providers named, with their countries |
| Subprocessors | In trust centre, behind a request | Listed publicly on the security page |
| Breach timeline | None stated | Contain within one business day, clinics told at first reasonable opportunity, 24-month record |
| PIA | Ontario Health's, summary only | Full template, offered to every clinic |
| Responsible disclosure | Yes | Security page and security.txt |
| Tracking on the website | Google Tag Manager, advertising cookies | None |
| Certification | ISO 27001, SOC 2 | None. Not needed without hosted data |
| Pen test | Yes, on request | Own suite only. Independent test still open |
| Company and insurance | WELL Health, cyber insurance | Two individuals. Still open |
